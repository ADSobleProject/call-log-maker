통화록 변환기

.txt → 통화록(.md · .docx)

예시 보기

삼성 통화녹음·음성녹음에서 내보낸 .txt를 고르거나 내용을 붙여넣으면 기본 정보 · 키워드 · 요약 · 할 일 · 전체 대화가 담긴 통화록을 만들어 줍니다.

🔒 파일이 서버로 전송되지 않습니다. 모든 처리는 이 휴대폰 안에서만 이뤄지고, 광고·추적·로그인도 없습니다.

1 기록 가져오기

삼성 “음성녹음” 앱 → 녹음 선택 → 공유/저장 → 텍스트(.txt)

또는 붙여넣기

2 상대방 · 일시 자동으로 채워지고, 고칠 수 있어요

3 통화록 미리보기

위에 .txt를 고르거나 내용을 붙여넣으면 여기에 통화록이 나타납니다.

이렇게 쓰면 좋아요
  • 통화 직후 파일을 고르면 상대방·일시가 파일명에서 자동으로 채워집니다.
  • 복사하기를 누르면 통화록 전체가 Markdown으로 복사돼 노션·메신저에 바로 붙일 수 있어요.
  • .docx 저장은 Word·한컴오피스에서 바로 열립니다. 공유는 휴대폰 공유 시트로 보냅니다.
  • PC에서는 녹음 파일(.m4a)까지 변환됩니다 — PC 버전 안내.
  • 홈 화면에 추가하면 주소창 없이 앱처럼 열립니다(크롬: 우상단 ⋮ → 앱 설치 / 홈 화면에 추가). 한 번 열어 두면 인터넷이 없어도 그대로 실행돼요.
  • 안드로이드에서는 다른 앱에서 공유 → 통화록 변환기를 누르면 .txt 파일이나 고른 글이 바로 이 화면으로 넘어와 통화록이 만들어집니다. 공유 메뉴에는 홈 화면에 앱으로 설치한 상태에서만 뜨고, 음성 파일(.m4a)은 .txt로 변환한 뒤 공유해 주세요.
